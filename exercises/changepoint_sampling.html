76  Inferring a changepoint

| Download notebook

Data set download

In ?exr-changepoint-model, you developed a model for a changepoint analysis. The text of that problem is repeated below.

Consider the following twist on the experiment we have been considering where a retinal ganglion cell’s spiking is monitored under constant light. The retina is exposed to constant light, but at some time between the start and end of the experience, the impinging light intensity changes. That is, for \(0 \le t < t_\mathrm{switch}\), the retina is exposed to one light intensity, and for \(t_\mathrm{switch} \le t \le T\), it is exposed to another. The problem is that you do not know what \(t_\mathrm{switch}\) is, and you have to infer it. Your task is to construct a Bayesian model for this situation, complete with prior predictive checks.

This is a simple example of a decoding problem, in which a stimulus is inferred from neuronal signals.

Your take is to infer the neuron firing rates before and after the changepoint as well as the changepoint itself.

76.1 Solution

We will model the spiking rate as a logistic function,

\[\begin{align} \beta(t) = \beta_1 + \frac{\beta_2 - \beta_1}{1 + \mathrm{e}^{-k(t-t_\mathrm{switch})}}, \end{align} \]

where \(s\) is time of the changepoint. The parameter \(k\) is a measure of how rapidly the changepoint comes about. The likelihood for the spike times is

\[\begin{align} f(\mathbf{t}\mid \beta(t)) = \left(\prod_{i=1}^n\beta(t_i)\right)\exp\left[-\int_0^{t_n} \mathrm{d}t\,\beta(t)\right]. \end{align} \]

The integral for the above defined \(\beta(t)\) is

\[\begin{align} -\int_0^{t_n} \mathrm{d}t\,\beta(t) = -\beta_1\,s + (\beta_1 + \beta_2)t_n+\frac{\beta_2}{k}\,\ln\left(1 + \mathrm{e}^{-k(t_n-s)}\right) - \frac{\beta_1}{k}\,\ln\left(1 + \mathrm{e}^{k(t_n-s)}\right) - \frac{\beta_2 - \beta_1}{k}\,\ln(1 + \mathrm{e}^{ks}). \end{align} \]

df = pl.read_csv(os.path.join(data_path, 'rgc_spike_times_change_point.csv'))
t = df['spike time (ms)'].to_numpy()
n = len(t)

data = dict(n=n, t=t)
sm = cmdstanpy.CmdStanModel(stan_file='changepoint.stan')
samples = az.from_cmdstanpy(
    sm.sample(
        data=data, max_treedepth=15, adapt_delta=0.95, iter_warmup=5000, iter_sampling=4000, thin=4
        )
)
